## 🎯 Proposta do Projeto
Este projeto foi desenvolvido com o objetivo de consolidar conceitos de manipulação de DOM através de JavaScript Vanilla. Ele resolve o problema comum de sorteios rápidos (como dinâmicas, jogos ou tomada de decisões) de forma fluida, sem a necessidade de recargas na página (SPA feeling) e com total adaptação a telas mobile.

## 🚀 Funcionalidades Principais
- **Geração Randômica Instantânea:** Sorteia números de forma imediata com o clique de um botão.
- **Configuração de Intervalos:** Lógica nativa preparada para trabalhar no intervalo dinâmico de 1 a 100.
- **Responsividade:** Interface adaptada para smartphones, tablets e desktops (Mobile-First approach).

## 🛠️ Tecnologias Utilizadas
A arquitetura do projeto foca na simplicidade e no desempenho, utilizando tecnologias nativas da web para carregar instantaneamente:

- **HTML5:** Estruturação semântica da aplicação.
- **CSS3:** Estilização moderna e layout flexível (Flexbox/Grid).
- **JavaScript (ES6+):** Manipulação dinâmica do DOM e lógica de aleatoriedade usando a API matemática nativa.

## 💻 Como Executar o Projeto Localmente

Não há necessidade de dependências complexas ou ferramentas de build. Para rodar a aplicação localmente:

1. Clone este repositório:
   ```bash
   git clone https://github.com
   ```
2. Navegue até a pasta do projeto:
   ```bash
   cd sorteador-Eletronico
   ```
3. Abra o arquivo `index.html` diretamente no seu navegador, ou utilize extensões como o **Live Server** no VS Code.
